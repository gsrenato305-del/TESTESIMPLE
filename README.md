# Simplefit App 🏋️‍♂️✨

Aplicativo Android Fitness desenvolvido em Kotlin e Jetpack Compose com design Cyberpunk/Neon.

## Como publicar no GitHub pelo Celular

1. No GitHub, crie um novo repositório chamado `Simplefit`.
2. Extraia este arquivo `.zip` e faça o upload da pasta inteira ou adicione os arquivos no repositório.
3. Acesse a aba **Actions** no GitHub para ver o aplicativo sendo gerado automaticamente em 3 a 5 minutos.
4. Faça o download do arquivo `Simplefit-App.apk` e instale no seu celular!
